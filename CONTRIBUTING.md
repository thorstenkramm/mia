Contributions are welcome through GitHub issues and pull requests.

## Pull Requests

- Keep each pull request focused on one change.
- Add or update tests for observable behavior, authorization boundaries, and regressions.
- Run `./run-all-tests.sh` before requesting review when the change affects Go, Markdown, OpenAPI, shell scripts, or
  dependencies.
- Do not submit secrets, credentials, personal data, or provider payloads.
